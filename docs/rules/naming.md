# Naming conventions

- Kotlin source filenames use `snake_case.kt`.
- Kotlin classes, interfaces, objects, and sealed result variants use `UpperCamelCase`.
- Kotlin functions, properties, parameters, and local variables use `lowerCamelCase`.
- Android resource names remain `snake_case` because the Android resource toolchain requires it.
- Java public type filenames keep the exact `UpperCamelCase.java` type name required by the Java compiler.
- Serialized keys and analytics/log event names are compatibility contracts and are not renamed with source identifiers.
