# Privacy policy draft

Parallel_app stores session names, selected application package names, profile choices, onboarding status, and monthly quota usage locally on the device.

Parallel_app does not read, modify, transmit, or sell game data. It does not use accessibility services, location spoofing, macros, memory modification, or anti-cheat bypasses.

Creating a work profile uses Android's managed provisioning consent flow. Android displays the requested administrative role before the user accepts it. Removing the managed profile deletes applications and data stored inside that profile.

This draft must receive the publisher's legal and Play Console review before public release. Publisher identity, contact details, retention periods, and the public policy URL remain to be supplied.
