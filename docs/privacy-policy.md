# Privacy policy

Parallel Game Space stores session names, selected application package names, profile choices, and onboarding status locally on the device.

Parallel Game Space does not read, modify, transmit, or sell game data. It does not use accessibility services, location spoofing, macros, memory modification, or anti-cheat bypasses.

The free version uses Google AdMob to display advertising. Google may process device identifiers, diagnostics, approximate location derived from network information, and ad interaction data according to the user's consent choices. The app requests consent where required before loading ads and provides privacy options when applicable.

Google Sign-In and Firebase Authentication process account identifiers, display name, and email address when the user chooses to sign in. RevenueCat processes an app user identifier and purchase information to validate Premium access. Google Play processes device metadata and application version when checking for critical in-app updates.

Session names and selected games remain in local app storage until the user deletes them or clears the app's data. Account and purchase records are retained by the relevant service providers under their published retention policies. Users can sign out in the app and may contact the publisher to request help with account-related data.

Creating a work profile uses Android's managed provisioning consent flow. Android displays the requested administrative role before the user accepts it. Removing the managed profile deletes applications and data stored inside that profile.
